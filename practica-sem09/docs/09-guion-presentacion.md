# Guion de presentación individual

1. **Problema (1 min):** una PYME recibe alertas heterogéneas y necesita priorizar sin respuesta automática.
2. **Arquitectura (2 min):** enseñar Compose y explicar frontend → backend/PostgreSQL, n8n y triage.
3. **Seguridad (2 min):** iniciar como lector y mostrar RBAC; explicar Argon2, JWT, secretos de entorno y auditoría sin tokens.
4. **Demo E2E (3 min):** importar/activar n8n, ejecutar simulador, demostrar severidad baja filtrada y alta triada con proveedor `heuristic-demo`.
5. **Dashboard (2 min):** explicar KPIs, MTTT y tasa de FP `sin datos` hasta revisión humana.
6. **Incidente/reportes (2 min):** crear/revisar incidente, exportar PDF/DOCX/XLSX, observar auditoría.
7. **Modo integrado (1 min):** mostrar variables Ollama/conectores, aclarar que no se probó integración externa ni se ejecutan bloqueos.
8. **Cierre (1 min):** limitaciones, matriz de pruebas y relación ISO/NIST.
