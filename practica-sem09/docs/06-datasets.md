# 6. Datasets públicos recomendados

No se descargan datasets masivos automáticamente.

| Fuente | Enlace / formato | Utilidad | Limitaciones / licencia |
|---|---|---|---|
| CIC-IDS2017 | [Canadian Institute for Cybersecurity](https://www.unb.ca/cic/datasets/ids-2017.html), CSV/PCAP | Tráfico benigno y ataques para ejercicios de detección | Entorno de laboratorio; revisar términos del sitio antes de redistribuir. |
| UNSW-NB15 | [UNSW Canberra](https://research.unsw.edu.au/projects/unsw-nb15-dataset), CSV/PCAP | Clasificación de tráfico y features | No representa todos los entornos PYME; verificar condiciones de uso. |
| CISA KEV | [CISA Known Exploited Vulnerabilities](https://www.cisa.gov/known-exploited-vulnerabilities-catalog), CSV/JSON | Priorizar vulnerabilidades explotadas | Catálogo, no eventos de red; gobierno de EE. UU., revisar términos. |
| MITRE ATT&CK | [MITRE ATT&CK](https://attack.mitre.org/resources/attack-data-and-tools/), STIX/JSON | Contexto de tácticas, técnicas y mitigaciones | Licencia Apache 2.0 para contenido ATT&CK, revisar versión y atribución. |

Usarlos solo con finalidad académica, anonimizar datos y documentar versión/fecha de descarga.
